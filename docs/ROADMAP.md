# 🎬 影片編輯器 — 功能擴展路線圖

> 從浮水印工具進化成完整影片編輯器
> 主人授權：可自由延展功能（2026-02-01）

## ✅ 已完成（原始需求）
- Phase 0: 技術研究 + UI 設計
- Phase 1: 基礎框架 + 影片匯入 + 預覽
- Phase 2: 浮水印匯入 + 拖放定位 + 尺寸調整
- Phase 3: 透明度 + 移動效果 + 輸出
- Phase 4: 儲存設定 + 批次處理
- Phase 5: 跨平台打包 + 測試

---

## 🚀 Phase 6 — 基礎剪輯功能
**目標：從「浮水印工具」升級為「輕量影片編輯器」**

- [ ] 時間軸 UI（Timeline）— 底部可縮放的時間軸
- [ ] 影片裁切（Trim）— 設定起點/終點，剪掉不要的部分
- [ ] 影片分割（Split）— 在時間軸上切割成多段
- [ ] 片段排序（Reorder）— 拖放調整片段順序
- [ ] 影片合併（Concat）— 多個影片接在一起
- [ ] 播放頭（Playhead）— 時間軸上的播放指示器

## 🎨 Phase 7 — 文字疊加 + 字幕
**目標：加入文字/字幕能力**

- [ ] 文字疊加層（類似浮水印，但是文字）
- [ ] 字體選擇 + 大小 + 顏色 + 描邊
- [ ] 文字動畫（淡入淡出、打字機效果）
- [ ] SRT/ASS 字幕匯入
- [ ] 字幕時間軸編輯
- [ ] AI 自動字幕生成（Whisper 整合）

## 🎵 Phase 8 — 音訊處理
**目標：影片的聲音也能編輯**

- [ ] 音訊波形顯示（在時間軸上）
- [ ] 音量調整
- [ ] 靜音/取消靜音片段
- [ ] BGM 添加（匯入音樂檔案）
- [ ] 音訊淡入淡出
- [ ] 分離音訊軌（影片音訊 + BGM 獨立控制）

## ✂️ Phase 9 — 進階剪輯
**目標：接近專業編輯器的能力**

- [ ] 多軌道時間軸（影片軌 + 文字軌 + 音訊軌 + 浮水印軌）
- [ ] 轉場效果（淡入淡出、滑動、縮放等）
- [ ] 影片濾鏡（亮度/對比/飽和度調整）
- [ ] 色彩校正（基礎 LUT 支援）
- [ ] 影片速度調整（慢動作/加速/倒放）
- [ ] 畫中畫（PiP）
- [ ] 裁剪/旋轉/翻轉

## 📦 Phase 10 — 進階輸出 + 發布
**目標：一站式從編輯到發布**

- [ ] 多格式輸出預設（YouTube / Instagram / TikTok / Twitter）
- [ ] 自動調整解析度和比例
- [ ] GIF 輸出
- [ ] 影片封面擷取
- [ ] 直接上傳到平台（YouTube API / 社群分享）
- [ ] 輸出佇列（排隊多個輸出任務）

## 🤖 Phase 11 — AI 功能
**目標：AI 加持，讓剪輯更智能**

- [ ] AI 自動剪輯（偵測精彩片段）
- [ ] AI 自動字幕（Whisper）
- [ ] AI 場景偵測（自動分割場景）
- [ ] AI 背景移除（綠幕效果）
- [ ] AI 畫質提升（超解析度）
- [ ] AI 配樂建議

## 💡 產品定位

**「輕量但強大的跨平台影片編輯器」**

目標對手：
- CapCut（功能多但隱私疑慮）
- Shotcut（開源但 UI 醜）
- DaVinci Resolve（太重太專業）

我們的優勢：
- 🔒 完全本地處理，無隱私問題
- 🎨 現代化 UI（深色主題、直覺操作）
- 🤖 AI 功能整合
- 📦 輕量（Tauri，不是 Electron 那種肥大）
- 🆓 開源
