## 1. 設計風格

### 設計原則

- **深色主題**：影片工具標配，降低長時間使用的眼睛疲勞
- **功能導向**：常用操作一步到位，進階選項收摺
- **即時回饋**：所有調整即時反映在預覽區
- **最小化干擾**：UI 不搶影片預覽的注意力

### 色彩系統

| 用途 | 色碼 | 說明 |
|------|------|------|
| 背景（主） | `#1a1a2e` | 深藍黑色，主面板底色 |
| 背景（次） | `#16213e` | 側邊面板底色 |
| 背景（元件） | `#0f3460` | 卡片/輸入框底色 |
| 強調色 | `#e94560` | 按鈕、進度條、選中狀態 |
| 強調色（次） | `#533483` | hover 狀態、次要按鈕 |
| 文字（主） | `#eaeaea` | 主要文字 |
| 文字（次） | `#8892b0` | 輔助說明文字 |
| 邊框 | `#2a2a4a` | 分隔線、邊框 |
| 成功 | `#00c853` | 完成狀態 |
| 警告 | `#ffa726` | 警告提示 |
| 錯誤 | `#ef5350` | 錯誤提示 |

### 字體

- **主字體**：Inter（UI 文字）/ Noto Sans TC（中文）
- **等寬字體**：JetBrains Mono（座標數值、路徑顯示）
- **大小**：13px 基準，標題 16–20px

### 參考風格

取 DaVinci Resolve 的沉穩專業感 + CapCut 的簡潔直覺操作，避免過度複雜的專業影片編輯介面。

## 4. 各元件詳細設計

### 4.1 影片預覽區

```
┌─────────────────────────────────────────┐
│                                         │
│    ┌───────────────────────────────┐    │
│    │                               │    │
│    │         影片內容               │    │
│    │                               │    │
│    │    ┌──────────┐               │    │  ← 浮水印覆蓋層
│    │    │ LOGO.png │               │    │     可拖放定位
│    │    │    ○─────┤               │    │     四角有 resize handle
│    │    └──────────┘               │    │
│    │                               │    │
│    └───────────────────────────────┘    │
│         ↑ 黑邊（letterbox）              │
│                                         │
│    ▶  ●━━━━━━━━━━━━━━○──────────  05:30 │  ← 播放控制
│                                         │
└─────────────────────────────────────────┘
```

**功能細節：**
- 影片以 `object-fit: contain` 模式顯示，保持原始比例
- 非影片區域顯示深色背景（letterbox）
- 選中的浮水印顯示虛線邊框 + 四角 resize handle（8x8px 小方塊）
- 未選中的浮水印僅顯示圖片本身
- 播放控制列：播放/暫停、進度條（可拖動）、時間碼
- 預覽區右鍵選單：適應視窗 / 原始大小 / 50% / 200%

**浮水印互動：**
- 點擊浮水印 → 選中（顯示邊框 + handle）
- 拖動浮水印 → 移動位置（即時更新右側面板座標）
- 拖動 handle → 縮放（預設鎖定比例，按住 Shift 自由縮放）
- 雙擊浮水印 → 開啟該浮水印的屬性面板
- Delete 鍵 → 刪除選中浮水印（確認對話框）

**面板行為：**
- 預設顯示 3 個浮水印欄位（可空）
- 「新增浮水印欄位」按鈕可新增更多（無上限）
- 每個浮水印卡片可收摺/展開（點擊標題列）
- 「同上」勾選框：啟用後灰化（disable）尺寸和透明度控制項，自動複製前一個浮水印的值
- 面板可捲動（當浮水印數量超出可視範圍時）
- 選中預覽區的浮水印時，對應面板卡片高亮並自動捲動到可視範圍

## 8. 響應式考量

### 8.1 視窗縮放佈局適應

| 寬度範圍 | 佈局策略 |
|---------|---------|
| >= 1280px | 標準雙欄佈局（預覽 65% + 面板 35%） |
| 1024–1279px | 雙欄佈局（預覽 60% + 面板 40%） |
| < 1024px | 禁止縮小（最小寬度 1024px） |

**面板可拖動分隔線：**
- 使用者可拖動預覽區和面板之間的分隔線
- 預覽區最小寬度：480px
- 面板最小寬度：280px
- 面板最大寬度：50%

### 8.2 影片比例適應

```
┌──── 橫式 16:9 ────┐   ┌── 直式 9:16 ──┐   ┌── 方形 1:1 ──┐
│ ┌────────────────┐ │   │   ┌──────┐    │   │  ┌────────┐  │
│ │                │ │   │   │      │    │   │  │        │  │
│ │   影片內容     │ │   │   │      │    │   │  │ 影片   │  │
│ │                │ │   │   │ 影片 │    │   │  │ 內容   │  │
│ └────────────────┘ │   │   │ 內容 │    │   │  │        │  │
│  寬度填滿，         │   │   │      │    │   │  └────────┘  │
│  上下留黑邊         │   │   │      │    │   │ 取較小邊     │
└────────────────────┘   │   └──────┘    │   └──────────────┘
                         │ 高度填滿，     │
                         │ 左右留黑邊     │
                         └───────────────┘
```

**關鍵規則：**
- 影片始終使用 `object-fit: contain` 模式
- 浮水印座標是相對於**影片實際顯示區域**，而非整個預覽容器
- 視窗縮放時，浮水印跟隨影片等比例縮放，保持相對位置不變
- 座標面板顯示的是最終輸出的實際像素座標，非預覽座標

### 8.3 高 DPI 支援

- 所有圖示使用 SVG
- 浮水印預覽使用原始解析度渲染，按 CSS 縮放
- 文字使用 rem 單位，支援系統字體縮放
