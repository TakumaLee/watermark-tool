## Unresolved scope

- Cairo, Game Music Emu and VAAPI need the exact snapshot or build-source reference used by Gyan. No replacement version has been silently substituted.
- The README's version section is not an exhaustive transitive dependency inventory. Its enabled-libraries list also names bzlib, lzma and zlib without version entries; further dependencies and toolchain build information are not established by these 42 rows.
- Upstream archive availability was checked as recorded above. Except for the three inspected MSYS2 source packages, these checks do not imply all source archives were fully downloaded or rebuilt.
- This index supplies concrete source-access directions and records remaining gaps. It must not be labeled “complete corresponding source” while the gaps above remain unresolved.
