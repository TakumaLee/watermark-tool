A FEW DETAILS

你可能想知道。

現在可以下載使用嗎？

可以。下載區提供 Windows x64 的 EXE／MSI 安裝包與版本說明；原始碼也已在 GitHub 公開。安裝包內含影片處理工具，不必另外安裝 FFmpeg。

這是網頁工具，還是桌面軟體？

這裡是產品介紹網站。Watermark Tool 本身是桌面軟體，核心浮水印與影片輸出在自己的電腦上處理，不需要把影片上傳到這個網站。

支援 Windows、macOS 或 Linux 嗎？

目前提供 Windows x64 安裝包。macOS 與 Linux 尚未提供已驗證的安裝版本；開發者可參考 GitHub 的原始碼與建置說明。

目前的預覽效能如何？

開發版在切換片段或拖曳時間軸時仍可能有短暫停頓。目前仍有已知的預覽效能限制，可在 GitHub 回報使用情況。

遇到安裝或使用問題，怎麼回報？

可以到 GitHub 開啟 Issue，附上 Windows 版本、軟體版本與重現步驟。請先移除私人影片內容與敏感檔案路徑，也可以透過下方 Email 聯繫作者。
